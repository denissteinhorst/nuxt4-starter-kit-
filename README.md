# nuxt4-starter-kit-
The Nuxt 4 Starter Kit is the predecessor of the Nuxt 3 Starter Kit and a plug and play solution for all your developer needs. We're talking: different Environments, Testing, Staging, Typing, Linting n'Everything already pre-configured. Heck, I even added full-fledged demo components! Everything to bring you up to speed 🚀
